# خطة إصلاح المنصة المالية: تسجيل دخول المستفيدين، الروابط الخاصة، والمزامنة الفورية

تهدف هذه الخطة إلى حل المشاكل المبلغ عنها جذرياً وضمان عمل المنصة بأعلى كفاءة وسرعة وموثوقية.

---

## المشاكل المستهدفة وحلولها الجذرية

1. **مشكلة تسجيل دخول المستفيدين عبر الرابط العام (`https://service-5financial-investment-platform.ai.studio` أو رابط التطبيق العام):**
   - **السبب المحتمل:** تباين في التحقق من بيانات الاعتماد أو حساسية المسافات/الأحرف في `username` و `password` عند المطابقة عبر خادم المصادقة `/api/auth/beneficiary/login`.
   - **الحل:** تنظيف المدخلات (تخفيف الفراغات وتحسين مطابقة `bcrypt` أو الدعم المرن لأسماء المستخدمين) وضمان استجابة سريعة ودقيقة بدون أخطاء "اسم المستخدم أو كلمة المرور غير صحيحة" للمستفيدين المسجلين.

2. **مشكلة الروابط الخاصة بالمستفيدين (صفحات تسجيل الدخول المخصصة بالـ Slug):**
   - **السبب الفني:** دالة استخراج ال slugs من مسار المتصفح (`getClientSlugFromUrl`) لا تتعامل بالشكل الأمثل مع المسارات النسبية الأساسية (`BASE_PATH` مثل `/financial-platform/client/slug`).
   - **الحل:** تحديث دالة تحليل الـ URL في التوجيه الأمامي (`App.tsx`) لدعم مسارات الأساس (`BASE_PATH`) بدقة بحيث يفتح رابط المستفيد الخاص صفحته المخصصة بشكل فوري وبدون أخطاء 403 أو توجيه خاطئ.

3. **مزامنة قاعدة البيانات الفورية لجميع المستفيدين الجدد:**
   - **السبب:** التحديثات الدورية كانت بطيئة أو لا تُزامن القوائم المعروضة في شاشات الإدارة والمعاينة بشكل فوري.
   - **الحل:** تعزيز استجابة الـ API وزيادة كفاءة استعلامات التحديث في `beneficiaries.ts` و إضافة التحديث اللحظي الفوري عند إضافة أو تعديل أي مستفيد من شاشات الإدارة أو المعاينة.

---

## خطوات التنفيذ

1. **تحديث مسارات وتوجيه الـ Slug (`App.tsx`):**
   - تحسين `getClientSlugFromUrl` للتعامل مع مسارات الـ Base Path بدقة تامة.

2. **تحسين مسار مصادقة المستفيدين (`auth.ts`):**
   - ضمان تنظيف مدخلات اسم المستخدم وكلمة المرور ومقارنتها بسلاسة تامة.

3. **تحسين المزامنة والتحديث الفوري (`App.tsx` & Backend):**
   - تسريع جلب وتحديث قائمة المستفيدين عند أي عملية إضافة أو تعديل من لوحة التحكم أو شاشات المعاينة.

4. **التحقق والاختبار الفني (`compile_applet`):**
   - التأكد من سلامة البناء البرعجي وعدم وجود أخطاء في الـ TypeScript أو التنفيذ.
